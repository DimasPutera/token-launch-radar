    How implied value is computed

    One function scores every row, from the snapshot's own figures. No protocol name is special-cased.

    Peer multiple
    Median market-cap-to-TVL of live-token protocols in the same category, from this snapshot. A category with fewer than 3 live protocols uses the global median instead. Clamped to 0.05–1.50.
    Growth
    Seven-day TVL change, clamped to −60%…+120%, then halved in effect: growth multiplier = 1 + growth / 100 × 0.5.
    Maturity
    Time since first listing, capped at 3 years: 0.6 + min(age, 1095) / 1095 × 0.4. A protocol with no listing date counts as 365 days.
    Breadth
    One extra chain adds 2%: 1 + 0.02 × min(chains − 1, 9), from 1.00 to 1.18.
